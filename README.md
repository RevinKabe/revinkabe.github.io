# GitHub Pages crawler preferences

This repository publishes the origin-level robots.txt for revinkabe.github.io.

The rules apply only to the /hochzeit/ project and its slashless URL. Other project sites are unaffected.

These are voluntary instructions to compliant crawlers, not authentication or a guarantee against scraping. The rules do not control access to GitHub repositories or raw.githubusercontent.com.

Deploy from main, directory / (root). Do not add a custom domain or a redirect here: the crawler rules must remain available at https://revinkabe.github.io/robots.txt.
